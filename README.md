## AI model development

A long-term hobby project focused on learning **model development rather than only model usage**.

### Current direction

- [ ] Train and experiment with small models under tight hardware constraints.
- [ ] Start with text-to-text learning and establish strong evaluation baselines.
- [ ] Explore teacher→student distillation to transfer useful behavior into smaller models.
- [ ] Generate and curate synthetic data with stronger teacher models, then evaluate the student carefully.
- [ ] Iterate on data quality, architecture, training and evaluation instead of chasing parameter count alone.

### Long-term direction

Explore whether a **compact multimodal / omni model** can become a practical personal daily-driver model for text, image, audio and video tasks.

> The goal is to learn the full loop: **data → training → evaluation → optimization → deployment**.
