## AI model development

I'm building this as a **learning project to understand the complete model-development loop**, not just how to call an API.

### Current direction

- [ ] Train and experiment with small models under tight compute constraints.
- [ ] Start with text-to-text modeling and establish reliable evaluation baselines.
- [ ] Explore **teacher→student distillation** to transfer useful behavior into a smaller model.
- [ ] Build synthetic-data pipelines using stronger teacher models, followed by filtering and evaluation.
- [ ] Iterate on **data quality, architecture, training, evaluation, and optimization** rather than focusing only on parameter count.

### Long-term direction

Explore whether a **compact multimodal / omni model** can become a practical personal daily-driver model for text, image, audio, and video tasks.

> **Data → Training → Evaluation → Optimization → Deployment**

That loop is the real project.
